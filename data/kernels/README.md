# Kernels

Download these files into this folder. Run the commands from the project root in PowerShell:

```
curl.exe -o kernels/naif0012.tls https://naif.jpl.nasa.gov/pub/naif/generic_kernels/lsk/naif0012.tls
curl.exe -o kernels/de440s.bsp https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp
curl.exe -o kernels/pck00011.tpc https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc
```

Also download the newest `moon_pa_de440_*.bpc` from
https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/
and the newest `moon_de440_*.tf` from
https://naif.jpl.nasa.gov/pub/naif/generic_kernels/fk/satellites/
