Lunar Landing Site Navigator - DesertStar

this was a great project and experience, we really putted our time there, but sadly when participating the city choose only 200 teams out of 1000, and sadly we are not one of them, so i made this project public that maybe someone will find benefit in it, and also to check for improved version check the branch that is related to 3d or something, we used python as a backend and react as a frontend.

to run it first go to the root directory of the project and use this command 
```
python -m venv venv && source venv/bin/activate && pip install -r api/requirements.txt
uvicorn api.main:app --reload
```
then go to /frontend and run this command
```
npm ci && npm run dev
```
